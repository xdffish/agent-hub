# 本地 Skill 规范补齐计划

范围：保持当前 macOS 产品行为，补齐已确认的权限边界、IPC 类型生成、扫描开销和工程记录。不引入云服务、后台代理或统一凭据存储。

## 技术设计

- 采用本地 `tauri` 总入口，关联 planning、security、framework-security、ipc、dialog 和 develop 技能。部分示例存在占位调用，以当前官方 API 和实际编译结果核实。
- Tauri AppManifest 显式注册受 ACL 管理的应用命令；按只读盘点、路径选择、资源计划、应用变更、MCP 检查和文档入口划分 capability，全部限制在本地 `main` 窗口。
- Rust 使用原生文件选择器产生限用途路径授权；持久项目只允许已添加路径。共享库路径由后端从资源 ID 计算，不信任交换包或设置中的任意 folder 字段。计划在应用和恢复前重新核查写入目标范围。
- 文件应用、Git 克隆和 MCP 执行/联网需原生确认；不把前端对话框当作安全授权。原生取消无写入、无启动。
- 使用 tauri-specta / Specta 根据同一份 Rust 命令注册表生成 TypeScript 参数、结果类型和调用函数，消除动态 command string；生成文件可校验是否漂移。
- 每次扫描为共享库建立一次指纹索引，并按 canonical path 缓存源 Skill 指纹；不跨扫描持久缓存文件内容，保证重新扫描能发现变化。
- 状态归属：授权、预览、文件快照与执行留在 Rust；前端只维护选择和展示状态，不能直接指定计划内容或进程配置。
