# 第一版实现与验证记录

日期：2026-11-10。版本：0.1.0。本文件记录已实现内容，产品目标见 [product-spec.md](product-spec.md)。

本文保留初版的实现与验证记录。2026-11-12 的 Windows/Linux 适配及当前验证范围见 [cross-platform.md](cross-platform.md)。

## 本地 Skill 规范补齐

上一轮初版没有先读取项目本地 Tauri 技能。本轮按总入口和适用子技能补齐，设计与逐命令范围见 [security-scope.md](security-scope.md)，实施清单见 [hardening-plan.md](hardening-plan.md)。

- 从单份注册表生成 18 个应用命令的 ACL，与 TypeScript 绑定同步；只允许本地 macOS main 窗口，无通用 fs/shell/http/dialog 前端权限。
- 项目与交换文件由 Rust 原生选择器按用途授权。共享库 folder、计划路径、符号链接与 Agent 写入位置由后端再次校验。
- 应用文件变更、Git 获取使用原生确认。MCP 检查使用一次应用内确认，后端核对预期配置指纹；取消不执行操作。MCP 子进程限制默认环境，远程明文 HTTP 限回环地址。
- 使用固定匹配版本的 tauri-specta 生成参数、结果和 DTO；前端不再使用动态命令字符串或手写跨语言数据结构。`npm run bindings` 更新绑定，隔离检查检测生成文件漂移。
- 共享库按每次扫描建立一次指纹索引，同一个 canonical Skill 目录按扫描缓存指纹；下一次扫描重新读取内容，不使用跨扫描的陈旧缓存。
- 关闭和退出等待活动操作完成；新导出文件使用 create_new，避免并发覆盖。

后文“8 项检查”和最初 GUI 导入/撤销记录是初版验证基线，并非本轮新增检查数量。

本轮验证：17 项隔离/Mock IPC 检查通过，生成绑定漂移检查通过，TypeScript/Vite 构建及 Rust/Prettier 格式检查通过；已重新构建 macOS 应用包并在真实窗口确认扫描可用。检查范围新增窗口/远程来源 ACL、跨用途路径授权、越界写入、共享库路径重定向、TLS、缓存读取次数、导出不覆盖、受限进程环境和活动操作生命周期。

原生选择器/确认对话框的取消交互尚未完成 GUI 验收。观察期间窗口被其他操作切换，停止自动接管，没有把这一部分记录为通过。本轮未写入真实 Agent 配置，未运行真实 MCP，也未连接外部 Git 仓库。

## 技术组成

- Tauri 2 原生宿主与单实例插件；Rust 实现扫描、配置适配、资源快照、事务预览及备份。
- React 19、TypeScript、Vite 构建界面；图标使用 Lucide，字体随应用打包，无外部字体请求。
- `src-tauri/src/scan.rs`：四端已知目录、Skills、MCP 配置及插件 manifest 发现。
- `commands.rs`：项目、Skill 来源与版本、分配、配置变更、导入导出和恢复入口。
- `app.rs`、`files.rs`：应用私有状态、快照校验、差异、备份、应用与失败记录。
- `mcp.rs`：显式触发的 stdio / Streamable HTTP 初始化检查，12 秒超时，不调用业务工具。

## 已实现流程

1. 启动只读盘点已知全局位置，主动添加项目后才扫描该项目。使用 PATH 和应用目录作为 Agent 程序发现依据，不执行程序来判断版本。
2. 本地目录或 HTTPS Git 来源导入 Skill，选择仓库内目录，记录来源和提交或内容指纹。Git 拉取有超时、禁止交互提示，不运行 Skill 附带脚本。
3. Skill 共享库支持固定版本、获取上游并比较、按 Agent 与作用域分配。更新共享库后需再次分配目标，避免自动覆盖目标中的自定义内容。
4. 使用普通文件副本分配，合并同一次操作中重复的目标路径。共享 `.agents/skills` 路径会被多个 Agent 读取，预览明确这一影响范围。
5. 改动先生成预览，再核对原始快照、保存备份并应用。出现外部修改时拒绝写入；部分失败记录失败状态，保留备份，提供恢复预览。
6. 成功操作可预览撤销；若目标有后续修改，阻止直接撤销。失败或中断记录可预览从当前内容恢复操作前备份，需用户再次确认。
7. 新增无凭据 MCP 配置只接受基础通用字段，并适配 TOML / JSON 差异。编辑原生同名项保留凭据和未知字段；更换传输方式需使用原生配置方式。
8. MCP 检查重新读取当前配置。stdio 临时进程使用独立进程组并在完成或超时时终止；HTTP 仅完成初始化并尝试清理会话。特殊鉴权 helper 与 OAuth 转交原生客户端处理。
9. 插件展示已知本地目录发现的 manifest，并提供各 Agent 官方插件管理文档入口；不修改内部插件数据库或缓存。
10. 导出、导入共享 Skill 文件、来源和版本，附带原分配参考；不会自动恢复原机器项目路径，也不导出 MCP 配置或 OAuth 凭据。
11. 应用单实例运行；关闭窗口退出，正在持有写入锁时阻止关闭，避免中断文件变更。

## 验证结果

- `npm run build`：TypeScript 检查与 Vite 构建通过。
- `cargo check --manifest-path src-tauri/Cargo.toml`：Rust 检查通过。
- `cargo test --manifest-path src-tauri/Cargo.toml`：8 项通过。覆盖外部修改阻止全部写入、私有备份权限与目录恢复、符号链接和路径穿越拒绝、Git 来源过滤与完整备份区分、敏感预览隐藏、盘点基准独立存储、四端 MCP 编辑保留凭据及未知字段与 TOML 注释、非法导入路径冲突。
- `npm run tauri build -- --debug`：成功构建本机 macOS `.app`。
- 实际窗口已检查首页布局与真实扫描：该次发现 227 个 Skill 位置、24 项 MCP 配置、59 个插件 manifest，四个 Agent 均有程序发现依据。数字是当时的本机快照，包含兼容目录和缓存清单，不等于独立资源数量或启用数量。
- GUI 实际走通：导入隔离测试 Skill → 内容与元数据差异预览 → 确认应用 → 历史记录 → 撤销预览 → 确认撤销；共享库恢复为空。
- GUI 关闭窗口后检查应用进程已退出。

验证只向应用私有库和隔离测试目录写入；未向真实 Agent 配置安装测试资源，未启动用户配置的 MCP，未登录 OAuth。测试导入与撤销记录保留在应用私有历史中。

## 明确限制

- 原生 Agent 是否加载、同名候选的最终优先级、Skill 专属 frontmatter 和依赖是否可用，尚未逐端运行认证。展示文件发现和原生确认提示，不能据此宣称跨端无损兼容。
- 当前按已知目录扫描，Skill 深度最多五层，插件深度最多六层，各根目录最多遍历 6000 项；不访问插件内部数据库。旧版路径作为候选来源，实际加载仍以目标版本为准。
- JSON 配置当前只支持标准 JSON；遇到 JSONC 或无效配置会停止该文件的解析与编辑，不清除注释。Codex 的 TOML 编辑保留其他表和注释。
- 普通源目录导入会解析其根符号链接；文件变更拒绝符号链接目标及包含符号链接的目录，避免意外影响共享目标。包含嵌套符号链接的 Skill 需先整理为普通文件。
- 单个资源最多 20 MB / 2000 个文件 / 2000 个目录；备份交换包最多 100 MB。Skill 导入拒绝常见凭据文件名，但无法识别正文或脚本中手工写入的所有秘密。
- 撤销以文件或完整 Skill 目录快照为单位，不自动合并后续修改。预览不是文件系统锁；无法阻止其他程序恰好在检查与写入之间并发修改。
- 配置备份可能包含已有凭据，存放在 0700 私有目录，文件为 0600；不读取系统钥匙串或原生 OAuth token 存储。
- Git 来源导入、导出再导入和外部 MCP 协议检查已有实现，但本轮未连接真实远端服务做端到端验收。
- 当前为本机构建；未做签名、公证、分发更新、跨设备自动同步或团队服务。
